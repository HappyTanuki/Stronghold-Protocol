# Native language packs + resource/audio extras

Pinned upstream: `c2a2ef778cf728ff29b953b9842b2a39b1e9cbea`, version 0.2.1.

The application uses upstream's Korean language pack and font setup unchanged. No custom translation dictionaries, DOM translator, extra display-language controls, clipboard/terrain translation hooks, Nanum Gothic faces or custom typography overrides are installed.

## Retained features
- Korean-client resource extractor: `overlay/extract-kr/`, still pinned to its proven extractor checkout. Do not repin it just to match the application revision.
- External `data/local-assets.json` and read-only asset tree. The regional board package is retained; unrelated assets are staged by upstream's asset downloader into a private tree.
- Independent persistent Korean/Japanese voice selection, using the existing voice volume control. Korean resolves to the same character/cue in Japanese when absent; Japanese is Japanese-only. Neither available means silence; never use CN as fallback.
- `prof.icon` URLs point to existing transparent profession glyphs. This retains the prior asset correction; it does not claim the user-reported residual icon bug is fixed.

Only five client files are patched. One upstream settings-test fixture additionally expects the new `voiceLanguage` field. Server/shared gameplay source, native language packs and CSS remain unchanged.

## Separate infrastructure
`overlay/guest-entry/` remains the Stronghold-only username-allowlist entry gate. It is not identity authentication and it does not grant access to the portal or other games. Proxy/authorization settings are preserved; `/packs/` requires the same Stronghold authorization as `/i18n/`.

## Build
Prepare a context with `upstream.tar` from the pinned Git archive, `extras/`, `artifacts/` and `Dockerfile.deploy` copied as `Dockerfile`. Artifacts include `assets.json`, `local-assets.json`, `voice-availability.json`, and `fonts/` generated by upstream's own `buildFonts()`. Game PNG/model/audio payloads are not in Git or the Docker image; mount the private external tree read-only at `/app/public/assets`.

```sh
docker build --network=host -t stronghold-native-kr:c2a2ef7 .
```

`apply-extras.mjs` checks exact preimages, patch hash and targets, postimages, artifact hashes and voice policy. The Docker verification stage runs 93 tests and native Korean strict validation, and rejects the retired translator/CSS/Nanum paths.

`stage-voices.py` uses the external ArknightsAssets2 voice branch: Japanese `voice/`, Korean `voice_kr/`. It records actual payload availability and source/output hashes. Missing files are explicitly unavailable, never fabricated. Audio provenance is separate from local Korean-client extraction.
